## 一句話核心

> PublicAPI.dev 是專門收錄免費公開 API 的線上搜尋平台，讓開發者不用逐一翻官方文件比較服務，直接集中查詢。

原貼文出處：Facebook 社團「AI 技術研究社 ChatGPT/Gemini/Claude/Codex 寫扣 x 教學 x 講幹話」（管理員 Shun-Jhih Jiang 分享）。

- 社群媒體

---

## 用途

- 快速搜尋、瀏覽與比較各類型 API 服務
- 減少自行搜尋官方文件或逐一比較服務的時間
- 可用於 **Vibe Coding** 時串接資料來源練習——需要什麼類型的資料源，先上去查有沒有現成免費 API 可以直接串
