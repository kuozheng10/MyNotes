# 滙豐旅人卡積分兌換核心 Tips

## 基本架構

**滙豐旅遊積分** → 可轉 16 家航空 + 3 家飯店（含雅高 Accor）

---

## 最佳兌換路徑（倍率排名）

### 路徑 A：旅遊積分 → 雅高 → 澳洲航空 QF ★最高 1.875x★
```
4,000 旅遊積分 → 6,000 雅高積分 → 7,500 QF 哩程
放大倍率：1.875x
```
- QF 屬寰宇一家，可兌換 **日航、國泰** 等 OW 航班
- 台北—大阪 商務艙來回：只需 **33,600 旅遊積分**（vs 亞萬需 64,000 哩）

### 路徑 B：旅遊積分 → 雅高 → FB（法荷航藍天飛行）= 1.5x
```
2,000 旅遊積分 → 3,000 雅高積分 → 2,000 FB 哩程
放大倍率：1.5x（在 +50% 活動期間）
```
- FB 屬天合聯盟，可兌換 **華航** 等 SkyTeam 航班
- 台北—溫哥華 商務艙來回：只需 **83,500 旅遊積分**（vs 華航哩程需 160,000）

### 路徑 C：旅遊積分 → 雅高 → IB → BA/QR = 1.5x（但 QR 開票超划算）
```
3,000 旅遊積分 → 4,500 雅高積分 → 3,000 IB 哩程 = 3,000 BA/QR Avios
放大倍率：1.5x
```
- IB/BA/QR Avios 可互轉
- QR 開票率極低：台北—大阪 商務艙來回僅需 **33,000 Avios + 稅 1,430 元**
- 換算只需 **22,000 旅遊積分**（vs 亞萬需 64,000 哩）

---

## 雅高積分價值
- 2,000 雅高積分 = 40 歐元 ≈ NT$1,467
- 每 1 雅高積分 ≈ NT$0.73
- 折抵雅高集團飯店住宿最直接

---

## 刷卡回饋換算
- **旅人無限卡**海外消費：10 元 = 1 積分
- 經過最佳路徑（→QF 1.875x）：等同 **~11% 現金回饋**，無上限

## 路徑D（2026-09更新）：旅遊積分 → 雅高(+50%) → Flying Blue(+20%) 雙重疊加 = 1.8x

> 來源：[FB社團「臺灣哩程研究社」貼文](https://www.facebook.com/share/p/1BpRsyviYs/?mibextid=wwXIfr)，派哥丟連結說「save sop」

跟路徑B(1.5x)是同一條轉點路徑，差異在**這次雅高轉Flying Blue本身也有+20%加碼**，兩層疊加放大到1.8x：

```
100,000 旅遊積分 → 150,000 雅高積分（+50%） → 180,000 Flying Blue哩程（+20%）
放大倍率：1.8x
```

**社群實測案例（松山-上海TSA-SHA經濟艙來回）**：
- 現金買票：NT$25,000
- 哩程兌換：Flying Blue **10,000哩**
- 倒算回旅人卡點數：只要**5,555點**，**1點發揮NT$4.5價值**（比路徑A的QF 1.875x還誇張，但這是短程線的極端案例，不是常態）
- 就算沒搭上雙重加碼、單純直轉Flying Blue：1點仍有NT$2.5價值

**Flying Blue隱藏優勢**：
- 除了天合聯盟本身，還能兌換澳洲航空、馬來西亞航空、日航、阿提哈德、西捷航空
- 支援「哩程減半/扣減」彈性兌換（最多折抵25%），哩程不夠時補一點稅費依然划算
- **福岡線表現優異**：華航直飛福岡來回商務艙只要**33,000哩**，換算每哩價值NT$1.57

**時間提醒**：雅高轉Flying Blue約需24-72小時到帳；若急著開票，建議直接從旅人卡直轉Flying Blue（不繞雅高），秒到帳。

⚠️ 兩則留言都在問「雅高轉Flying Blue+20%到什麼時候」，原作者沒回覆具體期限——**活動有時間限制，辦理前務必先上HSBC/雅高官網核對加碼是否還在**，不要照這篇的數字直接假設現在還適用。
