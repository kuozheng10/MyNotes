# 沈伯洋讀書訣竅：先寫考卷，再補不會的

> 白話：回答家長「怎麼幫要考學測的高三生」。他建議**不要用「今天念 50 頁／第幾課」排進度**，而是**先直接寫考卷**，找出自己不會的地方，今天的進度就是「把這 5 個不會的搞懂」。做完就休息，休息也要先排好。
>
> （影片內容是我從字幕逐段擷取整理，3 分 37 秒）

## 1. 為什麼不要用頁數、章節排進度
- 課本是編的人把重點**平均分散**在各章，但每個人理解力不一樣：有些重點你一看就懂，有些很難
- 用「今天念 50 頁」排進度，結果容易念得很累：會的也硬念，不會的還是沒搞懂

## 2. 他的方法：還沒念就先寫考卷
1. 完全還沒念、還不懂的時候，**直接拿考卷來寫**，完全不念
2. 好處一：可以拿**好幾種不同的考卷**來寫，有點像模擬考
3. 好處二：寫完會有感覺「這題我連猜都猜不對」→ **發現自己擅長跟不擅長什麼**
4. 寫兩、三份都沒關係，目的是**找出自己哪裡不懂、哪裡不會**
5. 回去看資料時：
   - 「這題我模糊有印象，推得出來」→ 吸收很快
   - 「這題我連推都推不出來」→ 自然會慢下來
   → 念書速度會自動調配：**有些地方念很快，有些念很慢**

## 3. 今天的進度 = 搞懂幾個不會的點
- 例：寫完考卷發現 **5 個地方不懂** → 今天的進度就是**把這 5 個搞懂**，搞懂就可以休息
- 好處一：念書步調**自己抓**
- 好處二：避免**彈性疲乏**——照頁數念常常覺得好累，因為一大堆你不會、記不起來的，還是硬念了 50 頁
- 「今天大腦的量大概就是念完 5 個不會的」

## 4. 休息很重要
- 舉大谷翔平：一直強調睡覺很重要；最近常受傷，可能就是沒好好休息
- **大腦的休息非常非常重要**，然後讓自己快樂
- **事先安排計畫**：今天念什麼科目、寫幾份考卷、念完就休息、休息要做什麼 → 會一直期待休息到來
- 給家長：**要尊重小孩的休息時間**，一直叫他念書會彈性疲乏
