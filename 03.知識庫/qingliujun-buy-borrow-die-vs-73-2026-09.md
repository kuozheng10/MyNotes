# 買借死 vs 75/25（0050＋正二）：退休提領回測，結果只差 0.77%

## 核心結論

**「買借死」和「75% 0050 + 25% 正二」在退休提領情境下，長期結果幾乎一樣。**
截至 2026/8/28（2003 年起回測）：
- 買借死（扣掉全部質押負債＋利息後）淨資產 **2 億 1,653 萬**
- 75/25 組合 **2 億 1,487 萬**
- 差 166.7 萬 = **−0.77%**

林大仁（社團管理員）評語：「重點還是曝險控制，各種作法都只是不同的變形而已。」

## 什麼是「買借死」（Buy, Borrow, Die）

退休要生活費、又不想賣任何一股 0050：把 0050 拿去**質押**，要多少生活費借多少，股票續留市場、股息再投入，隔年再多借一點、連利息都滾進負債，從頭到尾不賣一股。

**但它的財務本質不是「不用本金」，而是把「賣股提領」換成「質押負債」：**
- 例：退休 1,000 萬 0050，每年花 50 萬
  - 一般賣股：賣 50 萬 → 剩 950 萬股票、承擔 950 萬曝險
  - 買借死：不賣，質押 1,000 萬借 50 萬 → 帳面仍 1,000 萬股票 + 50 萬負債
  - **真實淨資產 = 1,000 − 50 = 950 萬，但仍承擔 1,000 萬股票曝險 → 槓桿 ≈ 1.05 倍**
- 每年續借、利息滾入負債，槓桿比率隨市場漲跌浮動
- **股市大跌時：股票市值縮、負債不縮 → 槓桿比率反而快速升高**

所以「一股不賣」只是包裝；買借死的本質＝**退休提領期間持續維持 >1 倍曝險，只是把槓桿放在自己的資產負債表上**。

## 回測設定

| | 買借死 | 75/25 |
|---|---|---|
| 起點 | 2003/6/30（0050 掛牌日）投入 1,000 萬 | 同左，750 萬 0050 + 250 萬 00631L |
| 提領 | 2004 起，首年 50 萬，每年 +3%（通膨） | 同左，直接賣 ETF 支付 |
| 槓桿來源 | 質押，固定利率 **3.8%**，日計息、半年複利；利息不賣股、直接增加借款 | 正二 ETF，目標曝險 75%×1 + 25%×2 = **1.25 倍** |
| 再平衡 | — | 正二權重 <20% 或 >30% 才拉回 25%；23 年共調整 28 次（23 次是年度提領順便平衡，只 5 次是門檻觸發） |

## 為什麼結果這麼接近

- 槓桿愈高結果愈好，但要算「取得槓桿的成本與路徑」
- 買借死：逐年增加的負債付 3.8% 利息
- 75/25：沒質押利息，但有正二費用 + **波動耗損**
- 買借死較高的市場曝險 ↔ 較高的融資成本，**彼此抵銷一部分**
- 75/25 目標 1.25 倍，實際平均曝險約 1.257 倍（區間 1.179–1.349），整段期間也都維持 >1 倍、相對穩定
- 買借死的平均曝險其實更高一點

## 兩者不完全相同的地方（風險落點不同）

- **買借死最大風險：利率與融資條件不完全掌握在自己手上**。大跌時股票市值↓、負債不縮、槓桿↑，券商可能調降擔保品成數、縮減額度、甚至補繳——通常正好是你最不想賣股的時候。這次回測沒觸發補繳，但那只是一條歷史路徑，不代表永遠安全。
- 正二 25% 不是神奇數字，是針對「這段歷史 + 3.8% 質押利率 + 這套再平衡規則」校準出來的。任一輸入改變，等效正二比例就會變。
- 回測都沒完整模擬：正二的期貨基差 / 追蹤誤差 / 交易稅 / 手續費 / 滑價；買借死的浮動利率 / 額度調整 / 券商雨天收傘。
- 嚴格說只測了「買」和「借」，沒模擬死亡後的債務清償、遺產與稅務。美國富豪的 Buy-Borrow-Die 有美國稅制背景（step-up basis），不能直接搬到台灣（台灣本來就沒證券資本利得稅＝免稅祕技）。

## 這張回測真正想告訴我們的事

許多名稱看起來完全不同的策略，只要把**負債、槓桿、成本、現金流**全部攤開，經濟本質可能非常接近。沒有免費的午餐。

**評估退休提領策略時，不要只問「有沒有賣股票？」**，而是問：
1. 領走相同生活費、扣掉全部負債與成本後，我還剩多少淨資產？
2. 為了維持這個報酬，我實際承擔了多少市場曝險？
3. 股市大跌 / 利率上升 / 流動性緊縮時，我還能不能繼續執行下去？

真正重要的：找到一套符合自身風險承受能力、市場不順時也能穩健執行的退休策略。
