# 宮古島自由行攻略（第一次去）

> 白話：宮古島景點很分散、公車不方便，**先決定要不要租車 → 再訂住宿 → 最後才排景點**。另外要先搞清楚自己是飛到「宮古機場」還是「下地島機場」，兩個差 30 分鐘車程。

## 一、兩個機場

| 機場 | 航線 | 備註 |
|---|---|---|
| **宮古空港** | 主要日本國內線 | 離市區近 |
| **下地島空港** | 部分國內＋國際線（羽田、神戶、那霸、首爾、釜山…依季節）；**星宇台北直飛也是降這裡** | 開車到市區約 **30 分鐘** |

**依抵達時間安排**
- 早上到 → 機場直接租車跑景點
- 下午到 → 先到飯店放行李，再去市區吃飯
- 晚上到 → **先確認租車公司營業時間**，以免取不到車

## 二、交通

| 方式 | 適合 | 注意 |
|---|---|---|
| **自駕（最推薦）** | 情侶、朋友、家庭 | 景點分散，看到喜歡的海灘就停 |
| 公車 | 住市區、慢旅行 | 很多景點沒到、班次少；一天只排少數幾個點 |
| 計程車 | 機場⇄飯店、短程 | 整天靠計程車很貴；可先下載 **DiDi Rider** |
| 包車一日遊 | 不開車、郵輪旅客 | 宮古島固定路線一日遊少，包車可指定景點 |

## 三、住哪區

| 區域 | 適合 | 優點 | 缺點 |
|---|---|---|---|
| **市區 平良** | 第一次去、沒租車 | 餐廳、超市、便利店集中 | 離部分海灘、大橋較遠 |
| **南部 前濱沙灘周邊** | 情侶、度假放空 | 海景、近前濱沙灘、來間大橋 | 生活機能少，沒車不便 |
| **西側 伊良部島／下地島** | 海景、拍照、遠離市區 | 近伊良部大橋、渡口の浜、17 END | 離市區遠，晚上覓食不便 |

作者建議：第一次去住**平良市區**最穩；有租車可以考慮海景度假飯店。

## 四、景點分四區（不要每天跨區折返）

| 區域 | 景點 |
|---|---|
| 市區生活圈 | 宮古神社、唐吉訶德宮古島店、熱帶植物園 |
| 南部海景圈 | **前濱沙灘**、來間大橋、龍宮城展望台 |
| 西部伊良部圈 | **伊良部大橋**、**渡口の浜**、**17 END**（看潮汐） |
| 北部池間圈 | 池間大橋、砂山海灘、宮古島海中公園（不下水也能看海底） |

**拍照時間**：前濱沙灘上午或傍晚；伊良部大橋傍晚看日落；17 END 出發前查潮汐。

## 五、什麼時候去
- 看海：**4～10 月**（海灘、浮潛）
- **7～9 月注意颱風**，航班和海況都會受影響

## 六、5 天 4 夜（自駕版）

| 天 | 行程 |
|---|---|
| Day 1 | 抵達 → 租車 → 市區入住 → 宮古神社 → 唐吉訶德 |
| Day 2 | 前濱沙灘 → 來間大橋 → 龍宮城展望台 |
| Day 3 | 伊良部大橋 → 渡口の浜 → 17 END |
| Day 4 | 砂山海灘 → 池間大橋 → 宮古島海中公園 |
| Day 5 | 市區早餐 → 伴手禮 → 還車 → 回台 |
