# Capital One Venture Rewards——史上最高獎勵，點數可轉長榮/日航

> 派哥丟連結說「save sop」。

## 開卡禮（限時，Trip+稱「史上最高」）

- **75,000哩程**，門檻：開卡後3個月內消費**$4,000**
- 額外**$300旅遊退額**（限透過Capital One Travel訂飯店/度假租屋使用，開卡一年內到期）
- TPG(2026/9)估算整體開卡禮價值約**$1,688**

## 卡片基本資料

- **年費**：$95美金
- **回饋**：所有消費無限**2x**點數；透過Capital One Travel訂飯店/租車**5x**
- **海外交易手續費**：0%
- **點數可轉入的常客計畫**：包含長榮航空(EVA Air)、日本航空(JAL)等多家航空/酒店集團

## 對派哥的意義

- 派哥的美卡策略主力是「集長榮」（見[[citi-thankyou-eva-air-2026-07]]），派哥人物側寫裡記過「長榮有Citi ThankYou 1:1、Capital One 4:3」——這張Venture Rewards就是那條Capital One轉長榮路徑的入門款，門檻比[[capital-one-venture-x-business-card]]（Venture X Business，$395年費/$30,000消費門檻）低很多
- $4,000/3個月的消費門檻對一般人來說相對容易達成，適合當作累積長榮哩程的第一張Capital One卡
- 無限2x回饋+0%海外手續費，對「消費高但不想花心思研究哩程」的人來說是平衡選項，這點呼應Trip+原文的定位

## 2026-09-29補：Trip+「五個理由」更新版文章的新細節

> 來源：[FB Trip+ 貼文](https://m.facebook.com/story.php?story_fbid=pfbid0299CEv7pMVbr1wLimG2PhCMbMEi5CVNN6LTWDiDqX1ho7YtubQ3KXZnUGzMQ5cDFsl&id=100068628994126) → [完整文章](https://blog.tripplus.cc/zh/148032/randy_newbie_5_reasons_to_apply_for_capitalone_venture)（Randy Wang，2026-09-27）。派哥丟連結說「save sop」。開卡禮數字跟上面一致（75,000 + $300），這篇多了下面幾點：

| 理由 | 新細節 |
|---|---|
| 1. 開卡禮 | 75,000 + 刷滿門檻本身的 2x 回饋 → 實拿**約 83,000 點** |
| 2. 靈活點數 | 可搭配 C1 現金回饋卡（**Spark Cash Plus、Savor**），把現金回饋轉成點數，再轉長榮 |
| 3. 購物保障 | **延長保固**：原廠保固 < 3 年的多送 1 年，每次最高 $10,000、每人上限 $50,000<br>**購物安全保障**：購買日起 90 天內損壞或失竊，每次最高 $500、每人上限 $50,000 |
| 4. 旅遊保障 | **租車險：美國以外是主要險（Primary）**，不用動自己的車險、保費不會漲；美國境內是次要險<br>**行李遺失／損壞**：每趟最高 $1,500，每 12 個月最多理賠 2 次 |
| 5. 日常刷卡 | 網購、修車、學雜費、家電這類「沒加成」的消費都有 2x，加上 0% 海外手續費，適合帶出國刷 |

**對派哥的新意義**：
- 派哥常出國自駕的話，「美國以外租車主要險」很實用，這是一般台灣信用卡比較少有的
- 手上如果有 Savor 類的 C1 現金回饋卡，可以跟這張組合，把現金回饋也轉進長榮

## 2026-10-11補：75,000 點開卡禮怎麼用（Trip+ Randy）

> 來源：[FB Trip+](https://www.facebook.com/share/1AqwyWvpRT/?mibextid=wwXIfr) → [完整文章](https://blog.tripplus.cc/zh/143986/randy_newbie_how_to_use_capitalone_venture_signup_bonus)（更新版，2026-01-22），派哥丟連結說「save sop」。

作者推薦四種用法：

1. **轉長榮（EVA）**：美國↔台灣單程皇璽桂冠艙（商務艙）
   - 直接兌換：美西 75,000 哩／美中、美東 80,000 哩
   - **升等（作者最推）**：豪經 → 商務：美西 31,500～35,000／美中東 36,000～40,000；經濟 → 商務：美西 50,000～60,000／美中東 58,500～70,000
2. **轉哥倫比亞航空 LifeMiles**：星盟商務艙、不收燃油附加費
   - 美國↔台灣單程商務 75,000（有折扣時可低於 70,000；有 LifeMiles+ 訂閱時看過 76,500 的長榮商務）
   - 美國↔歐洲單程商務 63,000
3. **轉日航 JAL**：自家航班的北美↔日本商務艙，兌換標準比用其他寰宇一家夥伴好
4. **轉英航 Avios 開伊比利航空**：美東（紐約／波士頓／華府／芝加哥）↔ 馬德里單程商務 40,500（淡季）／59,000（旺季）；美西南（洛杉磯／邁阿密／達拉斯）50,500／74,000

### ⚠️ 文章沒講的：轉點比例

- 本篇前面記的 **Capital One → 長榮是 4:3**：75,000 C1 點只會變成約 **56,250 長榮哩**
  - → **不夠直接換**美國↔台灣商務艙（要 75,000～80,000）
  - → **夠用來升等**：買豪經票再升商務（31,500～40,000），或經濟艙升商務（美西 50,000～60,000 勉強）
  - 所以作者說「升等比較划算」，對 C1 點數來說更是如此
- LifeMiles、英航 Avios 一般是 1:1；日航的比例我沒有另外查證，轉之前要先確認

**對派哥**：派哥的目標是「台灣出發」去日本的長榮商務艙（[[project_eva_award_tickets]] 那趟是 2027/5 日本 3 人），不是美國航線。56,250 長榮哩可以搭配 Citi TYP（1:1）湊數，或用在升等。
