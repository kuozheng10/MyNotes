# Guyton-Klinger 動態提領法（GK）：以 0050 回測 2003–2026

## 一句話

退休提領最難的不是「要不要賣股」，而是「市場差時生活費要砍多少、市場好時可以加多少」。GK 用四條規則把這件事變成每年一次的機械式判斷；本篇用 100% 0050 回測 23 年，結果亮眼（期末仍有 8,518 萬），但清流君強調**這不能證明「退休只買 0050 就好」**。

## 回測設定

| 項目 | 設定 |
|---|---|
| 起點 | 2003/6/30 投入 1,000 萬元 |
| 標的 | 100% 0050（還原股價，配息計入總報酬） |
| 提領時點 | 2004 年起，每年第一個交易日 |
| 初始提領率 | 5.2%（第一年領 52 萬，約每月 4.3 萬） |
| 後續調整 | 依台灣實際 CPI + GK 護欄 |
| 新資金 | 中途不再投入 |
| 回測終點 | 2026/8/28 |

需要生活費時賣出等值 0050（實務上可先用股息、不足再賣股，經濟本質相同）。

## 結果（圖表數據）

- 總共提領 **23 次**
- 累計提領 **1,864.7 萬元**
- 2026 年單年提領 **155.4 萬元**（約每月 13 萬）
- 期末資產 **8,518 萬元**（圖標 Final: NT$85.18M）
- 期間最低資產 **758.7 萬元**（2009/1/21）
- 通膨凍結 2 次、減額 10% 共 1 次、加薪 10% 共 10 次

最初投入 1,000 萬 → 累計領走 1,864.7 萬 → 帳上還剩 8,518 萬。看起來很誇張，但別急著下「5.2% 很安全」的結論。

## GK 規則怎麼運作

### 5.2% 只是「第一年」的提領率

之後每年判斷護欄時要重算「**今年預定生活費 ÷ 提領前資產**」。
例：去年領 60 萬、今年隨通膨變 61 萬，帳戶剩 1,000 萬 → 預定提領率 6.1%。

以初始 5.2% 為中心、上下偏離 20%，形成兩條護欄：
- **上方護欄 6.24%**
- **下方護欄 4.16%**

### 四項調整規則

| 規則 | 觸發條件 | 動作 |
|---|---|---|
| **❶ 通膨調整** | 一般情況 | 以前一年實際領取金額為基礎，按前一年度 CPI 調整（去年領 60 萬、通膨 2% → 今年 61.2 萬） |
| **❷ 通膨凍結** | 前一年投資報酬為負 **且** 今年預定提領率 > 5.2% | 取消這次通膨調整，生活費維持前一年金額（不是停止領錢） |
| **❸ 資本保存** | 預定提領率 > 6.24% | 當年提領金額 **減 10%**。原始規則在 40 年計畫最後 15 年停用此機制（避免晚年還被迫減生活費） |
| **❹ 繁榮加薪** | 預定提領率 < 4.16% | 當年提領金額 **加 10%**，且加減後金額成為「明年」計算的新基礎（一次調整影響延續到未來） |

### 護欄不是硬性上下限

4.16% / 6.24% 只是**觸發點**。提領率飆到 7%，GK 不會直接壓回 6.24%，只是把當年生活費砍 10%，砍完可能仍高於 6.24%。

### 每年操作流程

固定找一天 → 用 CPI 算今年生活費 → 檢查前一年報酬 + 目前提領率 → 決定照領 / 凍結 / −10% / +10% → 用股息或賣 ETF 取得現金。

## 2009 金融海嘯：規則真的踩了煞車

- 2008 初提領前：投資組合 1,575 萬
- 2009 提領前：只剩約 910 萬，前一年總報酬 **−42.1%**
- 通膨本應把生活費從約 67 萬 → 69.4 萬
- 前一年報酬為負 + 提領率已 > 5.2% → **通膨凍結**，維持約 67 萬
- 67 萬 ÷ 910 萬 = 7.36%，仍 > 6.24% 上方護欄 → **資本保存 −10%** → 實際領約 60.3 萬
- 之後 0050 續跌，資產一度只剩 758.7 萬

GK 的作用：不要求完全停止生活，也不假裝沒事照計畫加支出，而是**先少領一點，避免低點賣掉過多股數**。

## 市場大漲：退休生活費也能加薪

期間共觸發 **10 次繁榮加薪**：2006、2007、2011、2018、2020、2021、2022、2024、2025、2026。

2026 年例：年初提領前資產已成長到 5,382 萬，CPI 調整後原本預定領 141.3 萬（只占資產 2.63%，低於 4.16%）→ 再加薪 10% → 實際領 **155.4 萬**。

對比：若 52 萬只跟著 CPI 走、沒有任何加薪，2026 大約只會變 69.9 萬。實際卻領 155.4 萬 —— 差距主要來自 10 次繁榮加薪的累積，不是通膨。

> 退休金的目的不是讓帳戶好看，而是用來享受退休人生。

## 真正的代價：生活費不能完全固定

GK **沒有創造額外報酬**。它能從較高初始提領率開始，是因為退休者接受一項交換：**市場差時生活費可能暫停增加、甚至減 10%**。等於把部分市場風險從投資組合轉移到「退休者的生活費」。

實務建議：把退休支出分兩類，只對彈性支出套 GK：
- **必要支出**：吃飯、住房、保險、醫療 → 不能砍
- **彈性支出**：旅遊、娛樂、換車、大額消費 → 市場差時少一次旅行、延後換車

比「全部生活費一起減 10%」更符合真實退休生活。

## 這份回測「不能」證明的事（清流君自己強調）

1. **只是一條 2003/6/30 起的歷史路徑**。海嘯前投資組合已累積漲幅；若改成 2008 高點退休，報酬順序風險完全不同。
2. **只完成 23 次提領**。原始 GK 研究設定 40 年，還有 17 次未觀察，不能宣稱 5.2% 已通過完整 40 年考驗。
3. **原始 GK 的 5.2%～5.6% 是建立在股債現金分散配置 + Monte Carlo**（測 50/65/80% 股票），不是 100% 單一國家的 0050。原始 GK 還有一套資產管理規則（下跌後優先用現金/債券支付，避免股票負報酬時被迫賣股），單一 0050 無法重現。
4. 精確說法：這是「**0050 歷史總報酬路徑，套用 2006 年 GK 提領決策規則**」的回測，不是完整複製原始 GK 投資組合；原研究 99% 信心水準不能直接套到 100% 0050。

## 退休投資仍要保留全球分散

0050 可以是台灣投資人重要的股票部位，但不能因回測漂亮就推論「退休 100% 0050」。台灣人的工作收入、勞退、房地產、日常生活已經高度綁台灣，金融資產再全押 0050 = 工作/房產/退休金全集中在同一國家與少數產業。

全球分散不避免股災、也不保證每段期間贏 0050，作用是降低單一國家長期落後、產業集中、地緣政治與制度變動的風險。退休後沒有工作收入補虧損，分散更重要。務實做法：0050 當台股部位，另留一定比例全球股票，再依自己狀況彈性配置現金/債券。

清流君預告後續會回測「股債配置版 GK」（加債券、定期再平衡、提領順序），看能否降低股災期間波動與減薪次數、以及要付出多少報酬代價。

## 對派哥的用途

- GK 是「4% 法則」的動態升級版，把[[qingliujun-buy-borrow-die-vs-73-2026-09]]提到的第 3 個問題「股災時還能不能繼續執行」做成明確規則
- 四條規則可直接抄成退休試算表的邏輯（每年一次判斷）
- 關鍵心法：把退休支出拆「必要 / 彈性」，只對彈性支出套動態調整 —— 這條比規則本身更實用
- 對照組意義：買借死 / 75-25 / GK 都是在處理同一件事「退休期間的曝險與現金流管理」，沒有免費午餐

## 2026-09-22補：同作者第二套動態提領法——Vanguard動態提領（跟GK對照）

> 來源：[FB「清流君」貼文](https://www.facebook.com/share/1SHqMpMKkP/?mibextid=wwXIfr)，派哥丟連結說「save sop」。同一位作者、同樣用0050回測，這次換一套規則更簡單的「先鋒(Vanguard)動態提領法」，直接跟本篇上方的GK法對照。

### Vanguard法怎麼運作（比GK簡單很多，只有2條規則）

每年做法：先用「目前資產 × 5.2%」算出一個「目標提領金額(Target)」，再用兩條護欄夾住：
- **Ceiling（天花板）**：今年實質提領金額最多比去年**增加5%**
- **Floor（地板）**：今年實質提領金額最多比去年**減少2.5%**
- Target落在天花板跟地板中間 → 直接領Target；超過天花板 → 領天花板封頂；低於地板 → 領地板托底

**跟GK的關鍵差異**：GK管的是**提領率**護欄(4.16%~6.24%)，超出範圍才觸發加薪/減薪；Vanguard管的是**提領金額本身逐年能變動多少**(+5%/-2.5%)，5.2%只是每年重算Target時的計算基礎，不是實際年年都照領的比例。這也導致兩套策略在熊市/大多頭的反應完全不同：
- **熊市時**：GK會主動要求退休者減生活費(通膨凍結/資本保存-10%)保護剩餘資產；Vanguard優先避免生活費一年變動太大，寧可多賣一些資產換取生活費不要驟降
- **大多頭時**（例如2025~2026 0050狂漲）：GK只要提領率夠低就直接加薪10%；Vanguard的Ceiling反而會**壓住加薪速度**(一年最多+5%)，資產可能已經翻倍成長，但提領金額還跟不上，這也是為什麼Vanguard版最終資產(7,816萬)比GK版(8,518萬)還高的部分原因——並不是Vanguard比較會賺，是Ceiling把加薪速度鎖住了

沒有哪一套是免費午餐，只是兩者選擇把風險放在不同地方：GK的風險落在「生活費可能被迫砍」，Vanguard的風險落在「熊市時可能被迫多賣資產」。

### 回測結果（2003/6/30投入1,000萬，100%持有0050，2004年起每年首個交易日提領，回測到2026/8/31）

| 項目 | 數字 |
|---|---|
| 總提領次數 | 23次 |
| 累計提領 | 約1,854.5萬元 |
| 第一年提領 | 52萬元 |
| 2026年提領 | 約127.4萬元（實質購買力約94.8萬元，比第一年實質增加約82.3%） |
| 期末資產 | 約7,816萬元 |
| 期間最低資產 | 約751萬元 |
| 提領後最大回撤 | 約-59.4% |
| 觸發天花板(Ceiling)次數 | 15次 |
| 觸發地板(Floor)次數 | 6次 |
| 直接領Target次數 | 只有1次（2017年） |

**⚠️ 關鍵洞察**：22次「非首次」提領決策裡，21次都被Ceiling或Floor卡住，只有1次真的直接照Target的5.2%領——這代表「5.2% Vanguard動態提領」**不能理解成每年都把資產的5.2%領出來**，5.2%只是每年重新計算生活費「目標」的起點，最後真正領多少主要看護欄。

### 2005年(牛市)跟2008~2009年(金融海嘯)兩個實際觸發案例

- **2005年Ceiling生效**：2004年底資產約1,254萬，若完全照5.2%提領本可領約65.2萬，但前一年只領52萬——若直接跳到65.2萬等於生活費一年跳升25%以上，所以Ceiling把它壓到考慮通膨後最多55.5萬，沒領走的部分留在投資組合裡繼續成長
- **2008~2009金融海嘯Floor生效**：2008年底資產只剩約873萬，若完全照5.2%算，2009年Target只剩約45.4萬（前一年已領67.3萬，直接砍掉近三分之一），但Floor把降幅鎖在-2.5%，2009年考慮通膨後仍可領約67.9萬——**Vanguard並沒有像GK那樣主動把生活費大砍一刀，而是寧可多賣一些資產、換取生活費不要驟降**

### 這份回測「不能」證明的事（跟GK那篇的警語邏輯一致）

- 只是2003年起的一條歷史路徑，退休起點換成另一個時間(例如剛好碰上場高點)，結果可能完全不同
- 只有23次提領，還不是完整30年或40年退休期間
- 這次是100%持有0050，Vanguard原始研究示範的是**全球股債組合**，不是單一國家100%股票；資產配置、退休年限、支出彈性都會影響可承受的提領率

### 這篇真正值得學的地方

很多人研究退休提領第一個問題是「到底幾%提領率才安全？4%？5.2%？6%？」，但作者認為更值得思考的問題其實是：**你的退休生活費，有多少是真的不能動？又有多少可以調整？**——吃飯/住房/醫療/保險可能很難削減，但旅遊/娛樂/換車/比較高額的消費通常彈性較大。Vanguard原研究也把「支出彈性」列為影響退休提領能力的重要因素之一。所以動態提領真正重要的不是找到一個神奇的幾%數字，而是退休之前先想清楚：市場很差時我願意少花多少？市場很好時我又打算把多少投資成果轉換成更好的生活？退休可能長達二、三十年以上，不可能第一天就預測未來每一年的報酬/通膨/股災，與其猜一個數字然後假設永不遠調整，不如先建立一套「市場變了，我就怎麼調整」的規則——這才是動態提領值得學習的地方，不是GK或Vanguard哪一套比較神。
