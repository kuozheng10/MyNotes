# 河口湖公寓式旅館——早起被富士山美醒

> 派哥丟連結說「記一下」。⚠️ 原貼文沒寫飯店正式名稱，從留言的 Booking 連結推斷是「**The Garden 富士河口湖**」（Booking 網址 `the-garden-fu-shi-he-kou-hu-ting`），訂之前點連結核對一下。

## 重點

| 項目 | 內容 |
|---|---|
| 房型 | **2 人房到 6 人家庭房**（貼文標題寫 1–6 人房） |
| 景觀 | **每個房間陽台都看得到富士山**；部分房型**連浴室泡湯也看得到** |
| 設計 | 外觀到內裝都是白色系，新旅館，細節控會喜歡 |
| 設備 | 房內有簡易廚房設備；**洗衣機、腳踏車**免費給住客用 |
| 交通 | 步行到**河口湖站約 8 分鐘**；車站旁有超市 |
| 附近 | 離 FUJISAN SHOKUPAN（富士山吐司）很近 |
| 停車 | 有停車場，自駕或搭車都方便 |
